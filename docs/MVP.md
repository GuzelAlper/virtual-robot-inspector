# MVP симуляционного прототипа инспекционного робота

## Цель первой демонстрации

Показать минимальный сквозной сценарий работы виртуального робота-инспектора:

`Unitree Go2 → маршрут → контрольная точка → получение изображения → результат инспекции → сохранение данных`

## Состав MVP

- модель Unitree Go2 в Gazebo;
- простая промышленная сцена со стартовой зоной, коридором и препятствием;
- маршрут из 3–4 контрольных точек;
- одна тестовая станция;
- четыре виртуальных прибора: температура, газ, влажность и CO₂;
- автоматическое движение робота по маршруту;
- остановка робота в контрольной точке;
- получение изображения с виртуальной камеры;
- сохранение результата инспекции и времени выполнения;
- безопасная остановка при отмене миссии или появлении препятствия.

## Критерии готовности

MVP считается готовым, если:

1. Unitree Go2 запускается в Gazebo без критических ошибок.
2. Робот без ручного управления проходит маршрут из 3–4 точек.
3. Робот останавливается возле тестовой станции.
4. В контрольной точке сохраняется изображение с камеры.
5. Результат инспекции сохраняется в структурированном виде.
6. При отмене миссии робот безопасно останавливается.
7. При появлении препятствия робот останавливается или изменяет маршрут.
8. Сценарий можно повторно запустить после завершения или ошибки.

## Не входит в первый MVP

- полный полигон из 16 станций и 64 приборов;
- подключение физического робота;
- разработка собственной кинематики или алгоритма походки;
- сложное распознавание всех видов приборов;
- полноценный операторский интерфейс и итоговый аналитический отчёт.

Эти функции будут добавляться после проверки базовой сквозной цепочки.
